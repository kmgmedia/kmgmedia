I build software that does the work, not software that waits to be used.

Day to day that means two things: shipping full-stack web and mobile products, and wiring AI agents and automations into the workflows a business already runs on — the intake, the follow-up, the reporting, the parts nobody wants to do twice. I care about the version that survives contact with real users, not the demo.

Right now I'm building **Chowly** and a set of AI workflow systems, and I'm **open to freelance and contract work**.
